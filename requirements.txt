# Trois choix de fond, énoncés ici parce que c'est le premier fichier que vous
# ouvrez après le clone, et parce qu'ils expliquent des absences autant que des
# présences :
#
#   - Le pilote PostgreSQL est psycopg3 (`psycopg[binary,pool]`), pas
#     psycopg2 : le pool de connexions est dans le paquet, et l'asynchrone
#     n'exige pas de couche supplémentaire.
#   - Les embeddings passent par le paquet `openai`. C'est la seule dépense
#     récurrente obligatoire du cerveau ; elle est déclarée en première page du
#     README, pas ici.
#   - Ni Docker, ni orchestrateur : systemd et Python. Une machine que vous
#     savez déjà administrer, et des services que vous pouvez lire.
#
# Versions : contraintes minimales (>=) lisibles ici. Versions exactes
# installées figées dans requirements.lock.txt (`pip freeze` après
# l'installation). Les deux fichiers sont versionnés, le lock garantit la
# reproductibilité.

# LA DÉPENDANCE QU'ON NE VOIT QUE SUR UNE MACHINE NEUVE.
#
# `POST /cc/login` est la SEULE route non-GET du cockpit — donc sa seule porte
# d'entrée — et elle lit un formulaire. Starlette délègue l'analyse d'un corps
# `multipart/form-data` à ce paquet ; il ne s'installe PAS avec fastapi.
#
# Il manquait ici. Sur la machine où ce code a été écrit, il était présent
# (posé un jour par autre chose), donc invisible. Sur une installation neuve,
# le cockpit démarrait, `/cc/healthz` rendait 200, `provisioned` était vrai
# partout — et toute connexion rendait 500 en texte brut, sans une ligne dans
# le journal applicatif. Tout disait que l'installation était saine, et
# personne ne pouvait entrer.
#
# Trouvé par `tests/acceptance/acceptance.sh` (étape 7), qui installe sur une
# base vierge. Gardé par `tests/acceptance/test_dependance_du_formulaire.py`,
# qui exige l'analyseur tant qu'une route lit un formulaire — et cessera de
# l'exiger tout seul le jour où plus aucune ne le fera.
#
# Le nom du module importé (`multipart`) diffère du nom de la distribution
# (`python-multipart`) : c'est une des raisons pour lesquelles l'absence se
# cache si bien.
python-multipart>=0.0.9
